# BrightHaven Cleaning Website

Static, responsive website based on the supplied BrightHaven reference layout.

## Deploy
Upload index.html, styles.css and script.js to your GitHub repository, then enable GitHub Pages from Settings > Pages > Deploy from branch > main > /root.

## Working customer actions
- WhatsApp buttons open a pre-filled WhatsApp enquiry.
- Send Enquiry opens a pre-filled email.
- Quote form validates required fields.
- Responsive navigation works on mobile.
